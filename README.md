# Manav Jagtap Portfolio

Static portfolio built with HTML, CSS and JavaScript and ready for GitHub Pages.

## Customize before publishing
- Replace `YOUR_EMAIL@gmail.com` in `index.html`.
- Replace the LinkedIn `href="#"` with your profile URL.
- Add your Resume PDF to this folder and change the Download Resume link.
- Add/update project GitHub URLs.
- Edit education, skills and certification details if needed.

## Run locally
Open `index.html` directly, or in PyCharm right-click `index.html` and choose **Open in Browser**.

## Publish with GitHub Pages
1. Create a public GitHub repository, e.g. `portfolio`.
2. Upload/push these files to the `main` branch.
3. Open Repository → Settings → Pages.
4. Under Build and deployment select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
